# Synthetic Memory Forest

This is a fictional public fixture. `Aster Vale Observatory`, its instruments, its logs, and every event below were invented only to demonstrate the Memory Forest contracts.

This tracked tree is a detailed human-readable reference. Use `memory-forest init TARGET --example` to create a compact runnable demo with the same 00-06 route and private filesystem permissions.

## Demonstrated invariants

- Every proper name and identifier is synthetic.
- Structured wikilinks connect only adjacent layers.
- The STM leaf separates observation from conclusion and points to Daily provenance.
- The archive summarizes a reusable history without replacing current state.
- No layer grants authority or proves freshness.
